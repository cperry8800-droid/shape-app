## Architecture you'll need

- **The Record** = one algorithm (`bsScoreRecord`) in two twins (`.mjs` mobile/tested +
  `.ts` server) feeding `GET /api/client/score-record`. Both consumers (mobile page +
  website view) are thin renderers of `{ranges, history, lifetime}`. Rank basis excludes
  `store_redeem`, mirroring `deriveScore`, so the Record total = the Standing rank.
- **Awards** are day-pinned to the member's tz via `shape_user_tz(uid)` (INVOKER, not an
  RPC — locked to the award functions calling it internally as owner). The client sends the
  device `_localDate()`; the server validates against `(now() at time zone <tz>)::date`.
- **Self-drawing SVG traces**: `strokeDasharray`/`pathLength` self-draw is FRAGILE under
  `non-scaling-stroke` (renders a gap). For The Record's trend, a plain stroke was the fix;
  the `preserveAspectRatio="none"` + %-overlay-dot idiom (ladder-chart lesson) is fine.
