## Architecture you'll need

- **Voice pipeline:** `/api/ai/speak` → `resolveVoiceWithDefault(pick, env,
  tone)` + `NORA_TTS_INSTRUCTIONS || voiceStyleForTone(tone)` →
  `synthesizeSpeech(text, {voice, instructions})`. The verbatim contract is
  untouched: instructions steer DELIVERY only; `X-Spoken-Text` parity holds.
  Client: `window.ShapeVoice.speak(text, toneOverride, opts)` — server-only,
  `{ok:false, reason: 'signed_out'|'members'|'unavailable'}`; there is NO
  speechSynthesis anywhere in the voice path anymore.
- **Member gate in support chat:** `/api/support/chat` resolves the actor
  ONCE → `computeMembership` (fail-closed) → only then do the member layers
  exist: the context block, `MEMBER_TOOLS` schemas (memory + the 4 action
  tools + find_food), the direct-tool executor, and `isMember` threaded into
  the proposal ctx. A signed-out/prospect request is byte-identical to the
  pre-wave route.
- **`nora_memory` CAS contract** (`{rev, notes:[{id,text,at}]}`, cap 30 ×
  280 chars): every writer re-reads → mutates via the SHARED
  `normalizeMemoryDoc`/`applyRemember`/`applyForget`
  (`src/lib/ai/noraMemory.mjs` — the mobile Settings mirror IMPORTS it
  cross-root, the dashSignals precedent) → rev-conditioned update writing
  rev+1 → retry ×2 on genuine misses ONLY (strict error taxonomy:
  `read_failed`/`write_failed` surface immediately; insert retries only on
  23505). Server loop: `casWriteUserGoals` (`server.ts`); client loop:
  `noraMemCasWrite` (`shapeBackend.js`).
- **Member tool undo rule** (spec #1652, binding): the stale-write predicate
  rides IN the atomic UPDATE/DELETE — zero affected rows = throw
  `'Changed since — nothing undone.'`. Tables without `updated_at`
  (client_weigh_ins) condition on the full value snapshot; hydration's undo
  is the accumulator INVERSE (negative delta — documented deviation,
  preserves concurrent adds).
- **Day bucketing for Nora's writes:** `memberToday(ctx)` computes today in
  `client_profiles.timezone` (Intl, UTC fallback) — NEVER bare
  `toISOString()` for day-keyed member data (the `local-day.ts` contract).
- **PR watcher convention (memory: auto-merge-prs-when-green):** merge gates
  = required CI (Web · Mobile · **gitleaks**) + CodeRabbit check-run complete
  with no CHANGES_REQUESTED on the HEAD + a Codex review present (grace ~5
  min) with no P-badge findings. Codex threads never auto-resolve (GraphQL
  `resolveReviewThread`). Reasoned declines with receipts are house practice
  (#1656: find_food provenance token — the human confirm card IS the gate).
