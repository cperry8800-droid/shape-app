## Architecture / things to know

- **Atomic-write pattern (new this session):** when a route accumulates onto a row (read-then-
  write), use a `SECURITY DEFINER` RPC doing `INSERT … ON CONFLICT DO UPDATE col = … + delta`
  (the conflict-update reads the row under the upsert's lock). Clamp/validate inputs **inside**
  the RPC — it's executable by `authenticated`, so a direct caller bypasses the API guards.
- **JSONB subfield auth:** RLS scopes ROWS, not JSONB keys. To make `client_programs.detail.X`
  coach-only, the `client_programs_discipline_guard` trigger checks per-key (directive/goals
  coach-only; training/nutrition by discipline), enforced on the RPC AND any raw upsert.
- **Supabase default privileges gotcha:** `create or replace function` + Supabase ALTER DEFAULT
  PRIVILEGES auto-grant EXECUTE to `authenticated`/`anon`. To lock a function to service-role,
  `revoke … from public, authenticated, anon` (NOT just `public`) then `grant … to service_role`.
- **Font fallback metrics** live in `pageShell.jsx`'s shared `<style>` + the `--serif`/`--sans`/
  `--mono` stacks; extend to more inline-CSS marketing pages mechanically if needed.
