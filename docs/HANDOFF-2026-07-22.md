## Binding rules the wave established (see memory `cook-mode-wave`)

- **No fabricated parallelism** — interleaving needs authored `passive:true` +
  station + `min≥4`; a parsed duration never creates a window.
- **An annotation MEANS "the recipe's next step waits for this hold"** — never
  annotate a window whose next step is authored concurrent with it.
- **Board identity = `iid`** (per-instance), `recipeKey` is display-only;
  started-state lives in a durable ref that survives timer dismissal.
- **PREPPED = active-work signal** (ratified twice); make-aheads chill
  unattended, so Finish with a running terminal 'off' hold is design.
- **A terminal window must be station 'off'** — structural in `finishCookable`
  + catalog-tested (a live-fire hold can't outlive the board).
- **Never fabricate a timer** — any parse ambiguity (fractional durations)
  refuses a derived window/chip; the cook reads the step text.
