## 3. The cut machinery a next session needs

**Run a cut in this order.** Every step below exists because skipping it cost a round.

1. **Read the surface before keying it.** Fabrications first — a cut that translates a
   fabricated coach credit ships it in thirteen languages. Cuts 2, 5, 9 and 11 each found
   one.
2. **Split before you sweep.** If a value is *both* stored/compared *and* rendered, it needs
   a token/label split in its own PR (#1966 → #1967). Five instances have shipped, in order: the
   Train tag, the grocery aisle, the primary goal, the Settings pref options, the profile
   pin kinds/prompts. The class was swept tree-wide in cut 9 and came back clean.
3. **Derive the `en` catalog from the source's own `defaultValue`s** (an AST walk), so the
   catalog and the call sites cannot disagree at authoring time. That is how #1974 found a
   **prefix collision** that a hand-copied key list would have silently overwritten.
4. **Register the namespace in BOTH arrays** — `mobile-app/src/i18n/index.js` (what the app
   LOADS) and `tests/i18n-catalog-complete.test.mjs` (what gets VALIDATED). #1975 proved that
   dropping the runtime one leaves the entire suite green while the app reads English.
   That is now gated in three directions.
5. **Read per-locale terms out of the shipped catalogs**, never invent them. Reading the
   catalog is what separates a house convention from a guess.
6. **Re-point the ratchet in the same PR** and check the axes that should NOT move. A cut that
   moves `partStrings` when it should not is half-done.
7. **Mutation-test, with an unmutated sanity case at both ends of the batch**, and prove each
   edit landed (`grep`) before believing a survivor. Commit first; back up with `cp`, never
   `git checkout --`.
8. **Confirm the emitted bundle**, behind a **positive control** (a key that certainly ships)
   and a **negative control** (a key that does not). A saturated zero is the instrument until
   proven otherwise — this wave hit that five times.

### The nine blind shapes (why every count is a FLOOR)

The walk misses copy that is: plain JS never reaching JSX · in a **module-scope** array
literal · in a **local** array literal · in an **inline anonymous** array written into JSX ·
in an **object literal rendered by reference** · in a **template literal split at its
placeholder** · passed as a **call argument** · built inside a **state setter** · on a
**prop not on `TEXT_PROPS`**. So `hard` is a floor, and a `tr: 0, hard: 0` row means *the
walk found nothing*, never *there is nothing*.

### Traps that are now gated (do not re-open them)

- **`returnEmptyString: false`** — an empty catalog value renders the **RAW KEY**. Gated
  repo-wide by a derived non-empty assertion (landed at zero offenders).
- **The bare-word plural branch** — the parity gate reads ICU argument names with an ASCII
  identifier regex, so `one {workout}` is indistinguishable from a placeholder. **The fix is
  always in the DATA** (every branch leads with `#`), and the guard is *derived from
  `placeholders()`* rather than re-implemented. A Cyrillic/Vietnamese/Hausa bare branch is
  correctly **not** flagged — that is a documented equivalent mutant, not a bug to "fix".
- **The comment stripper** — `tests/helpers/strip-comments.mjs` is the one implementation,
  deliberately line-oriented. Import it. Its lazy predecessor opened a false block on
  `accept="image/*"` and swallowed 567,895 characters of the client file.
- **Assertions strip comments first** — the rationale written at a site quotes the very
  expression the guard bans.

## 7. Working notes that cost time this session

- **`git rev-parse --short HEAD origin/main` fails** — "Needed a single revision". Run the
  two revisions as separate invocations.
- **The ratchet's `DUMP=<Component>` hook** prints one component's strings. It lives in
  `componentsOfSource`, where the **`file` variable is not in scope** (it belongs to the
  caller `componentsOf(file)`) — so a file-qualified dump needs the caller loop, not the
  inner one. And `componentsOfSource` is also called with inline test fixtures, so a raw
  dump yields more rows than the real tree; cross-check names against the UNCOVERED baseline.
- **A saturated-zero measurement is the instrument until proven otherwise.** This wave hit
  it five separate times — a failed `cd`, a minifier rewriting `"key"` to a backtick, `\xA0`
  escaped in the emitted bundle, a template-built key of which only the prefix ships, and a
  `grep -oP` that this shell does not support. Always carry a positive control.
- **A mutation that reports a survivor is a broken instrument until the edit is proven to
  have landed** — three times in one cut. And landing *in the file* is not landing *where
  the guard looks*: a mutation that lands inside a comment the guard strips is a no-op.
- **A guard that fails is evidence about the guard until the code is read.** Several
  first-cut guards in this wave failed on correct trees (a `[^\]]*` class that could not
  cross a `]`, a lazy `[\s\S]*?` span that ran past its own branch, a marker that
  brace-matched a destructured parameter instead of a function body).
