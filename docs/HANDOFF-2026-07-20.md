## 4 · Review-process lessons (all three now standing practice)

1. **A clean CodeRabbit review submits NO review record.** Polling the reviews API for
   the head SHA hangs by construction on a passing PR. The edited-in-place summary
   comment (its commit-range line + "No actionable comments") is the done signal.
2. **Findings arrive in the review BODY as "outside diff range" comments** — two
   consecutive rounds on #1773 would have read as clean passes from the inline-comments
   list alone. Read the body every round.
3. **Codex auto-review fires once at PR open, no retry, no trace on failure.** The
   manual re-trigger is a PR comment: `@codex review`. #1770 shipped with no Codex
   review this way; #1773 recovered via the trigger. Post it whenever Codex is silent
   ~10 min after open.
4. Pattern worth naming from build 5's five rounds: **fix the CLASS, not the instance.**
   Twice a "fixed" contract stayed false because only the flagged coercion was repaired.
