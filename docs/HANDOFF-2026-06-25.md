## What shipped — Daily steps / NEAT (#1415)

Display-only daily steps (NEAT). Steps come from a connected watch
(**Apple Health / Garmin sync → `daily_health_snapshot.steps`**) — never manual
entry, since a person can't know their own count.

**Backend**
- `src/lib/health-snapshot.ts` — `steps` on `SnapshotPatch`.
- `src/app/api/integrations/apple-health/sync/route.ts` — `steps` in `ALLOWED_FIELDS`,
  normalized to a **non-negative integer** in `cleanPatch`.
- `src/app/api/integrations/garmin/webhook/route.ts` — dailies `steps` mapping;
  **rejects negative** totals.
- `src/app/api/client/progress/route.ts` — `series.steps` + `stepsLatest`/`stepsAvg`
  KPIs; the snapshot query uses **`select('*')`** (migration-safe — PostgREST 400s an
  unknown explicit column, which `?? []` would silently swallow).
- `src/lib/integrations/reconcile.mjs` — `steps` registered in `METRICS` so INT2 can
  reconcile multi-source conflicts.

**Mobile** (all in `mobile-app/src/broadsheet/iosAppBroadsheetClient.jsx`)
- **`BSStepsCard`** (Me page) — today's count vs goal. Honest `—` until today syncs;
  "Connect a watch" only when nothing has ever synced. Keyboard-activatable; opens history.
- **`BSStepsHistory`** — a tier-colored **ring instrument**: hero gauge (today) +
  **Week** (vertical day-list: ring + a bar filling toward goal + an `actual / goal`
  readout) + **Month** & **3-Month** ring calendars. Rings fill to the user's Shape
  Score tier color only at goal.
  - **Calendar-correct windows** (`windowDays`): the stat row matches the rendered
    rows, missed-sync days are honest gaps, and "today" = today's local date (not the
    last sample). Was the source of several review findings — keep this invariant.
- **Editable goal** — `window.ShapeStepGoal` cache + `useBSStepGoal()` hook +
  `BSStepGoalSheet` (typeable input + stepper + 6k–15k presets). Persisted to
  localStorage **and** `user_goals('client_step_goal')` (dedicated key — no clobber;
  a session `set()` wins over a late cloud `hydrate()`). Default 8000.
- **"Alive" rings** — injected `<style>` keyframes: staggered one-shot draw-in
  (`bsRingDraw`); a tier-colored **breathing glow on every completed ring**
  (`bs-ring-halo`, a **circular CSS `box-shadow`** so there's no square SVG
  filter-region clip; GPU-composited transform/opacity only, so the 30-ring month grid
  stays smooth); the hero gets an avatar-style pulsing outer ring (`bs-ring-live`) +
  a drop-shadow glow when filled. All gated behind `prefers-reduced-motion`.
- Steps page uses the standard nav bar (SHAPE logo + `Vol. 1 · No. 1` + search + tier
  avatar via `BSMeCorner`, all wired) + centered range tabs.

**Review** — CodeRabbit + Codex, two rounds each; every Critical/Major fixed (honest

## Architecture you'll need (build/deploy)

- **Mobile build (PowerShell, NOT Git Bash — Git Bash mangles `/m/`):**
  `cd mobile-app; $env:VITE_BASE='/m/'; npm run build`, then from repo root
  `Remove-Item -Recurse -Force public\m; Copy-Item -Recurse mobile-app\dist public\m`;
  confirm `/m/assets/` in `public/m/index.html`.
- **Parse-check JSX:** `node -e "require('./mobile-app/node_modules/@babel/parser').parse(require('fs').readFileSync('<file>','utf8'),{sourceType:'module',plugins:['jsx']})"`
- **Pre-commit hook** builds mobile in Git Bash → commit with `MSYS_NO_PATHCONV=1 git commit …`.
- **CRLF gotcha (bit us twice this session):** editing TS/MJS files can flip LF→CRLF
  on this machine and balloon the diff to whole-file churn. After editing, check
  `tr -cd '\r' < file | wc -c`; if non-zero, `tr -d '\r' < file > file.tmp && mv …`.
  `main` is LF; there's no `.gitattributes`.
- **No `gh` CLI on this machine** (and none expected). Use the GitHub REST API with the
  token from Git Credential Manager:
  `TOKEN=$(printf "protocol=https\nhost=github.com\n\n" | git credential fill | sed -n 's/^password=//p')`,
  then call `api.github.com` (create/merge PRs, read checks). Required CI checks to
  gate a merge: **Web (typecheck + build)** · **Mobile (build + public/m sync)** ·
  **Secret scan (gitleaks)**. CodeRabbit/Codex are advisory.
- **Staging preview URL:** `git push origin <branch>:staging --force` →
  `https://shape-app-git-staging-cperry8800-droids-projects.vercel.app/m/`. Poll the
  served bundle hash; use a **browser User-Agent** on curl or Vercel's bot-checkpoint
  returns 403.
