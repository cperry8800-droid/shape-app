### ⚠️ Environment note — local mobile Vite build is currently blocked

The background audit agents ran `npm audit`/`npm ci`, which perturbed the local install; my
repair reinstalls then re-downloaded `@tailwindcss/oxide`'s native `.node`, which **Windows
Application Control now blocks** (`"An Application Control policy has blocked this file"` on
`node_modules/@tailwindcss/oxide-win32-x64-msvc/tailwindcss-oxide.win32-x64-msvc.node`). The
mobile-app Vite build fails only because Vite walks up and loads the **root** `postcss.config.mjs`
(`@tailwindcss/postcss` → oxide); the mobile app itself uses no Tailwind.

- **Impact:** local `VITE_BASE=/m/ npm run build` can't run until the machine allows that binary
  (owner action: clear/allow it in the Windows security policy, or reinstall from an allowed
  source). **CI is unaffected** — it builds `/m/` on Linux (`scripts/build-m.sh`), which is the
  authoritative mobile gate; `public/m` is built at deploy, not committed.
- This is a machine-policy issue, unrelated to any code change this session.
