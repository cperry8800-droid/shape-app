## Architecture you'll need

- **Open Ledger primitives are the shared design language** (`iosAppBroadsheetClient.jsx`):
  `bsSdSplitUnit` / `BSSdCountUp` / `useBSSdInView` (ONE observer per card/section) /
  `bsSdReduced()` / keyframes `bsSdDrawX·GrowY·Stamp·Rise·Pop·Burst·PrBreath` (all inside
  the reduced-motion media block, injected by `bsInjectSessionDetailCss`). Every animated
  style spreads `...(reduced ? null : seen ? {animation} : {hidden-initial})`.
- **Heat discipline (feed)**: heat = the AUTHOR'S ROLE color (client teal
  `t.isLight?'#0a8f87':'#34d6c5'` · trainer rust `#c0533b` · nutritionist gold
  `t.isLight?'#a07a2e':'#d8b25a'`), line-only, closed placement list (rail · title period ·
  hero rule · type-tag underline · co-sign ✓ · details underline+chevron · comments tick ·
  boost fill · separator terminus). `tc` (TIER color) survives ONLY at the avatar ring +
  openDetail payload. NO infinite animations on feed cards.
- **Community feed container has NO horizontal padding** — cards run edge-to-edge, so
  `BSActivityCard` gets `pagePad={0}` there (both the internal branch review AND CodeRabbit
  independently caught a `t.padX` overshoot assumption). Profiles pass 0 too (their
  wrappers were stripped to bare full-bleed margins `0 -20px` / `0 -22px` in the fix wave).
- **`BSSdBars` is now HORIZONTAL** (#1529): rows = fixed 76px label column (+ tiny sub
  line) · bar track flex:1 drawing rightward via `bsSdDrawX` (staggered 110ms) · figure on
  the right edge (13.5px display tabular, RPE mini-dial beside it). Best row = heat fill +
  `bsSdBurst` + `bsSdPrBreath`. Used by Splits/intervals/sets AND Cadence (per-mile
  averages bucketed from the distance-uniform trace at the call site; min→max spread so
  clustered spm still reads; `Seg n` labels when distance unknown or 15+ mi).
- **Home slate rows** (`BSSlateRow`): grid `50px time / 58px tag / 1fr title / auto status
  / auto control` — the last track must stay `auto` (36px meal/habit ticks).
