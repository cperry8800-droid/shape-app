## Architecture you'll need

- **Type system (post-#1713):** `DISPLAY_BS = 'Saira', 'Space Grotesk', …`
  (`iosAppBroadsheet.jsx` ~line 24) — every `t.DISPLAY` title is Saira now, and
  the client module's 12 per-component `SERIF`/`SANS` aliases carry the same
  stack. `fonts.css` declares Saira as **3 variable-weight blocks**
  (`font-weight: 100 900`, files font-22/23/24.woff2). Gotcha recorded: the
  woff2 flag-encodes known table tags, so a naive byte-scan for `fvar`
  false-negatives — use fontTools to inspect. JetBrains Mono = instrument
  voice; Newsreader = editorial serif; system stack = body. Old notes saying
  "titles = Space Grotesk" are superseded.
- **Home rail (post-#1710):** `_leadBlock` renders the full lead (mono
  `{time} · YOUR MOVE` label · serif head · compact moves/macros · CTAs · the
  `hero-home` tour anchor) INLINE in the slate at its time slot; untimed leads
  sit at the rail's head. Slate rows carry source minutes (`_min`); untimed
  rows sort after timed ones; the NOW tick (`bsHomeNowPulse`) anchors only
  between timed rows, today only, driven by a once-a-minute `bsNowMin` state
  tick (same-value setState bails out). Home carries **zero BSPlates** now —
  the one-plate rule is satisfied by the inline lead.
- **Calendar accents (post-#1712):** `_BS_CAL_ACCENTS(t)` is the ONE kind →
  color map (training/sessions rust · meals teal · check-ins blue ·
  consults/plans/admin gold); `BSCalendarMonth` + the day reader resolve
  display color via `accentOf(e)` (map by kind, stored accent fallback) so
  demo arrays and live server events can't disagree. `bsCalTeal(t)` is the one
  teal helper. The register reads This month · Done · **Open** (not "Ahead" —
  stale past months).
- **Back buttons (post-#1711):** `BSBackButton` (shared chrome) IS the plain
  mono `← BACK`; new back controls should use it, never a bordered chip.
- **Adjust regeneration (post-#1708):** pure planner
  `mobile-app/src/services/adjustRegen.mjs` (base-load `baseL` scaling ·
  STABLE weekday remap · strict-future scope · repeat `repeatDow` patches ·
  182-cap horizon) → `window.ShapeAdjustRegen.apply` →
  `regenerate_client_workouts` RPC (transactional, coach-gated, 400/200/50
  bounds, `shape.adjust_regen` txn-flag quiets the notify trigger). Row-scoped
  `payload.adjustGen` vs `detail.training.gen` kills display double-scaling.
  Scaling constants live in adjustRegen.mjs — `bsClientWeekDemo` imports them.
- **Paid enforcement (post-#1704):** the edge proxy stamps
  `x-shape-gate: member` (stripped from incoming requests); route handlers
  trust the stamp as the fast path and re-run `computeMembership` only when
  it's absent. Faults fail open with a loud log.
