### #1381 — Compliance Waves 3 + 4 (the detail)
- **Data deletion** — `POST /api/account/delete`: `currentUser`-scoped (caller can only
  delete their own account); purges ~25 owned tables + 5 storage buckets (incl.
  `coach-credentials`); paginated bucket purge; writes an `account_deletions` audit
  row; `auth.admin.deleteUser`. **Requires auth-user deletion for an `ok:true`**
  (a data-only purge returns partial-failure). **Deliberately uses the service-role
  (admin) client** — 7 of the purged tables (incl. `user_goals`/health profile,
  `user_integrations`, `score_ledger`, `messages`, `trainers`/`nutritionists`) have
  **no user DELETE RLS policy**, so an RLS-scoped client would silently fail to erase
  the most sensitive data. Wired: client Settings (`clientMeSettings`), coach
  Danger-zone (`dashProfileExtras`), mobile (`BSDataCompliancePage`), all with a
  type-`DELETE` confirm.
- **Privacy-rights webform** — `public/privacy-request.html` → `POST /api/privacy-request`
  → emails `PRIVACY_EMAIL`. Returns **500 if the email can't be delivered** (was a silent
  false-success); `<noscript>` fallback + ARIA live region.
- **GPC** — `src/lib/gpc.ts` `gpcOptOut(request)` reads `sec-gpc:1`; middleware forwards
  `x-gpc-optout`; `pageShell.jsx` consent IIFE honors `navigator.globalPrivacyControl`.
- **Region-aware consent banner** — `pageShell.jsx` `shapeConsent()` IIFE (EEA via
  `Europe/*` timezone, GPC, `consent_log` insert keyed **per-user, only after a confirmed
  insert**, safe DOM). Banner colors use `var(--token, #fallback)`.
- **18+ age gate** — email `signUp` now **requires** a valid DOB (no soft-fail); phone
  signup ties account creation to create-mode (`shouldCreateUser: !!isCreate`) so a new
  account always carries a DOB; `ensureDobPersisted()` backstops the email-confirm + phone
  flows; `over_18` is recomputed from `date_of_birth` by a DB trigger (never client-trusted).
- **8 Wave-4 counsel docs** in `docs/legal/`: `ropa.md`, `dpia.md`,
  `transfer-impact-assessment.md`, `dpa-subprocessor-checklist.md`,
  `incident-response-plan.md`, `data-retention-schedule.md`,
  `legitimate-interests-assessment.md`, `accessibility-and-pci-notes.md`.

## 6. Gotchas learned this session
- **Windows case-collision**: the repo can track two paths differing only by case
  (`SHAPE-logo-white.png` vs `shape-logo-white.png`) with different blobs; Windows can hold
  only one physically, so the working tree shows a perpetual phantom "modified". Resolve
  with index plumbing (`git rm --cached` the dup + `git update-index --cacheinfo` the
  keeper) — not a normal edit. Fixed this session.
- **`git reset --hard origin/main`** and **prod-DB migration writes** are both blocked by
  the auto-mode classifier unless the user explicitly authorizes them — ask, don't work
  around.
- **The Workflow tool** (multi-agent drafting + adversarial review) worked well for the
  Code of Conduct legal copy — reuse the pattern for content-heavy / consistency-critical
  tasks.
