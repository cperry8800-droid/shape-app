## The critical find — award-RPC dedupe was broken for the WHOLE points system

`score_ledger_dedupe_idx` was a **partial** unique index
(`… WHERE source_kind IS NOT NULL AND source_id IS NOT NULL`), but **every** award RPC
inserts with `ON CONFLICT (user_id, source_kind, source_id) DO NOTHING` *without* the
predicate. Postgres rejects that against a partial index (SQLSTATE 42P10), so each RPC
(goal milestone, momentum, tier bonus, PR wall, check-in, community, accountability
penalties, commitment settle, store redeem) would **error the moment it fired** — i.e.
no points would ever credit. It had never surfaced because the awarding tables are still
empty (no real data). Fix (`2026-06-26-score-ledger-dedupe-fix.sql`): recreate the index
as a **plain** unique index (NULLs are distinct by default, so null-source rows still
never conflict — behaviorally identical) so the existing inference works. `award_step_points`
deliberately uses the bare `ON CONFLICT DO NOTHING` (index-agnostic). **Verified against
prod** before + after. If you ever re-issue an award RPC, the targeted form is now fine.
