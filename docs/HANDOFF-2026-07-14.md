## Gotchas learned today (save future debugging)

- **rAF first-frame negative t**: a loop keyed off `performance.now()`
  captured at eval can receive a FIRST rAF timestamp slightly earlier →
  negative `t` → `FX[Math.floor(-ε)]` undefined kills the loop. Clamp
  `ms = Math.max(0, now - start)` (the app's own `cycleColor` already guards).
- **The Settings takeover unmounts `BSRadioFx`** — the live overlay is never
  visible while Settings is open; that's why the picker has tap-to-preview.
- **Playwright vs the 6s preview**: MCP round-trips eat the window — assert
  inside ONE `browser_evaluate` (tap + setTimeout check in the same promise).
- **`npx http-server` caches hard** — serve scratch previews with `-c-1` or
  cache-bust, or screenshots show stale files.
- **Demo (signed-out) never persists `user_goals` writes** — a toggle that
  "does nothing" in preview may be fully wired signed-in (the ticker case).
