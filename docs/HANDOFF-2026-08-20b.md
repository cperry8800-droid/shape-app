## 7. Traps this session actually cost time

- ⚠ **`git checkout -- <file>` to undo a mutation wiped every uncommitted change in that
  file.** Already recorded in this repo; walked into anyway. **Mutation-test with `cp`,
  never with git**, and commit before starting.
- ⚠ **A fix that mutation-survives is not a fix.** Two of this round's changes left the
  suite green when reverted — coverage existed for a sibling site only. **Revert every fix
  and watch it fail before believing the test.**
- ⚠ **An alternation in an assertion hides which branch fired.** `/wait long enough|free
  burner/` passed for either reason code, so the test never exercised the case it was
  written for.
- ⚠ **A number in four records needs fixing in four records.** "I already corrected that"
  was true of one of them.
- **`\n` in a shell heredoc collapses**; build multi-line anchors with `chr(10)` or write
  the script to a file. **An apostrophe inside a single-quoted JS string** (`#1910's`)
  breaks `warroom.ts` — `tsc` catches it.
- **`grep -E "^. (pass|fail)"` cannot match the multibyte `ℹ`** node prints. Use
  `grep -E "(pass|fail) [0-9]+"`.
- **The mount harness installs no translator**, so copy renders its `defaultValue`
  verbatim — a catalog change without the matching `defaultValue` edit shows the OLD text.
