# Signal — Coach Profile (build) The SIGNAL living-identity direction, scoped to the **coach** personas: **trainer** and **nutritionist**, as a mobile app. Full-bleed on phones, framed phone on desktop, with **Persona** (Trainer / Nutritionist) and **Variant** (Public / Own / Private) toggles. ## Run Open `index.html` in a browser, or serve the folder: ``` npx serve . ``` (A static server avoids any local-file CORS quirks with the JSX modules.) ## Files - `index.html` — shell: fonts, React + Babel, Signal motion CSS, mounts the app - `signalCoachApp.jsx` — app wrapper (viewport switch, persona + variant controls, mount) - `livingSignal.jsx` — the Signal profile screen (rings / cardiac trace / core + feed) - `livingShared.jsx` — design system: tiers, coach data, marketplace blocks, phone chrome, helpers - `ios-frame.jsx` — iOS device bezel (desktop view only) ## Edit - Coach data lives in `LV_PEOPLE.trainer` and `LV_PEOPLE.nutritionist` in `livingShared.jsx` (certs, services/prices, reviews, disciplines, feed, tier). - The profile layout is `SignalProfile` in `livingSignal.jsx`; the instrument is `SignalSigil`. - Marketplace sections (certs, services, reviews) are `LvCoachBlocks` / `LvServices` in `livingShared.jsx`. - JSX is transpiled in-browser by Babel (no build step). For production, precompile the `.jsx` files and drop the Babel `
